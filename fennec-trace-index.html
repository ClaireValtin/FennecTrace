Help

Open files — drag & drop anywhere, use Open AB1…, or (installed as an app) double-click .ab1 files in Windows Explorer.

Select — click/drag on the trace. Ctrl+A selects the whole read, Ctrl+C copies the selected sequence. Arrow keys move the cursor, Shift+arrows extend, Home/End jump.

Right-click a selection — BLAST it (opens NCBI blastn), copy it plain / FASTA / reverse-complement.

Flip (RC) — reverse-complements traces, bases, qualities and numbering, so a reverse read is analyzed as forward. Exports follow the displayed orientation.

Sliders — H zoom stretches the trace horizontally; V zoom scales peak height.

Quality — bars above each base are Phred scores (amber < Q20). Gray shading marks the low-quality 5′/3′ ends (Mott trimming). Hover a base to read its exact Q in the status bar.

Het candidates — positions where a secondary peak exceeds the threshold are flagged in orange with their IUPAC code; open the list with the Het button and click an entry to jump there.

Search — IUPAC motifs allowed (R, Y, S, W, K, M, B, D, H, V, N); both strands are searched. Enter/F3 next, Shift+F3 previous.

Split view — stack two panes to compare forward and reverse reads of the same amplicon.
