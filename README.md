# FennecTrace

A fast AB1 chromatogram viewer for Sanger sequencing traces.

**Open it:** https://clairevaltin.github.io/FennecTrace/

## What it does

- **Open AB1 files** by drag-and-drop (several at once)
- **View traces** with zoom, Phred quality bars and shading of low-quality ends (Mott trimming)
- **Heterozygote candidates** – positions with a secondary peak above your threshold are flagged with their IUPAC code
- **Reverse-complement** a read so a reverse read reads forward
- **Split view** to compare forward and reverse reads side by side
- **Search** for motifs (IUPAC codes allowed) on both strands
- **BLAST** a selection directly at NCBI
- **Export** as FASTA, FASTQ or a PNG image of the trace

Files are read in your browser and never uploaded.

## How to use

Open the link above. It can also be installed as an app, which lets you double-click `.ab1` files to open them.
